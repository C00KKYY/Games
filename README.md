# Games

## [Verkehrsmeister 3D](verkehrsmeister/)

Verkehrs-Puzzlespiel in 3D: Farbige Häuser beliefern Ziele derselben Farbe, du baust die Straßen und hältst Kreuzungen mit Vorfahrt per Wisch, Ampeln, Kreiseln, Autobahn-Hochstraßen und Polizei-Einsätzen frei. Wochen mit Kartenwahl, sechs Städte mit eigenen Mechaniken (Klappbrücke, Bahnübergänge, Berge, Messe, Ring), Tageschallenge und Stau-Report.

Starten: `verkehrsmeister/index.html` im Browser öffnen.

## Tägliche Prototypen

Ein geplanter Agent baut jeden Tag einen neuen Spiel-Prototyp für CrazyGames (Arcade, Idle, Physik).

- Galerie: https://c00kkyy.github.io/Games/ (GitHub Pages, Branch `prototypes`)
- Bewerten: im jeweiligen Issue mit Label `prototyp` als Kommentar `Note: X/5` und `Status: ausbauen / verwerfen / egal`
- Arbeitsanweisung für den Agenten: [prototypes/AGENT_BRIEF.md](prototypes/AGENT_BRIEF.md)
- CrazyGames-Anforderungen: [prototypes/CRAZYGAMES_CHECKLIST.md](prototypes/CRAZYGAMES_CHECKLIST.md)
