# Grafik-Werkzeuge aus der Voruntersuchung

Kontaktbögen (`sheet.js spec.json out.png`) und Probeszenen (`mock.js`) für die Grafik-Optionen DCSS, Kenney und 0x72.
`spec_*.js` erzeugen die `spec_*.json` aus den Dateilisten (`dcss_list.txt`, `0x72_list.txt`, `td_index.json`).
Die Quellpfade zeigen auf die heruntergeladenen Pakete unter `/tmp/claude-0/overhaul/art/` (nicht im Repo);
benötigte Quellbilder kommen erst mit ihren Lizenzdateien nach `assets/src/` (Meilensteine M5/M6).
